## Sobre mí

Soy desarrollador full-stack y construyo **aplicaciones y sitios web a medida** para negocios que necesitan algo más que una plantilla.

Trabajo de punta a punta: desde la landing que atrae clientes hasta el sistema interno que ordena la operación — inventarios, cotizaciones, gestión de pacientes, catálogos. Mi stack principal es **Next.js + TypeScript** en el front y **Node / Python / Java** en el back, con PostgreSQL y Docker cuando el proyecto lo pide.

También me muevo en **infraestructura y redes** (Cisco Packet Tracer, despliegues dockerizados), así que puedo acompañar un proyecto desde el código hasta que está corriendo en producción.

**¿Tienes una idea en mente?** Escríbeme a [alexiszarate260@gmail.com](mailto:alexiszarate260@gmail.com) — respondo rápido.
